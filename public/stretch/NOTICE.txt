Stretch demonstration animations
================================

Sources: ExerciseGymGifsDB — https://github.com/JahelCuadrado/ExerciseGymGifsDB
         lyfta.app, liftmanual.com, fitnessprogramer.com (individual drills
         the dataset above doesn't carry). All trace back to Gym Visual.

NOTE: hip-flexor-lunge.webp came from fitnessprogramer.com and had a corner
site logo, which was painted out during conversion. Recorded here so the
provenance isn't lost and so it is dealt with at launch along with the rest.
Media:   © Gym Visual — https://gymvisual.com/
Format:  animated WebP, 300x300, converted from the source GIFs

The animations in this folder are Gym Visual's work, redistributed through the
dataset above. They are used here in a private, non-commercial app.

BEFORE ANY PUBLIC LAUNCH, one of the following must happen:

  1. License these clips directly from Gym Visual (roughly $0.90 each; the 24
     files here would be about $22), or
  2. Delete this folder.

Deleting the folder is safe and requires no code change: lib/stretchMedia.ts
falls back to the drawn figures in lib/stretchPoses.ts for any drill without a
clip, and the remaining drills already run on drawn figures today.

Each file is named for the POSITION it shows, and lib/stretchMedia.ts decides
which drill names may play it. Filenames are not pose slugs — a clip has to
match the position a drill names, not just the muscle it targets.
